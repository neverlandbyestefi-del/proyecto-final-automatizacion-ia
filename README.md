# proyecto-final-automatizacion-ia
Proyecto Final: Automatización de propuestas comerciales con IA

Autora: Estefanía Disalvo
Curso: Automatización con IA — Coderhouse

Objetivo

Automatizar la generación de borradores de propuestas comerciales mediante inteligencia artificial, con aprobación humana y comunicación interna a través de Slack.

Tecnologías

- Airtable: almacenamiento y seguimiento de solicitudes.
- Make: automatización de los escenarios.
- Cohere: generación de propuestas con IA.
- Slack: comunicación de propuestas aprobadas.

Funcionamiento

1. Airtable registra las solicitudes. 
2. Make envía la información a Cohere para generar un borrador.
3. La propuesta se guarda en Airtable para su revisión.
4. Una persona aprueba la propuesta antes de continuar.
5. Make envía la propuesta aprobada a Slack y actualiza su estado en Airtable.

Entregables

- Informe final en PDF.
- Blueprints de los dos escenarios de Make.
- Video demostrativo.
- Base de datos en Airtable.
